# Contributing to OctoAcme Project Management Hub

Thank you for helping us build a better, shared knowledge base for project management at OctoAcme!

## How to Contribute

### 1. Document a New Process
- Use the **[Process Documentation](/.github/ISSUE_TEMPLATE/process-documentation.md)** issue template
- Provide clear, step-by-step instructions
- Include who is responsible for each step
- Add related resources and success criteria
- Submit as an Issue or Pull Request

### 2. Suggest an Improvement
- Use the **[Improvement Suggestion](/.github/ISSUE_TEMPLATE/improvement-suggestion.md)** issue template
- Explain the current pain point
- Describe the proposed improvement
- Indicate who would benefit

### 3. Share Best Practices
- Create an issue describing a lesson learned or best practice
- Include real examples from your projects
- Explain the context and conditions where it applies
- Add to `docs/best-practices/`

### 4. Submit Documentation Changes
- Fork the repository
- Make your changes in the `docs/` directory
- Submit a pull request with clear descriptions
- Reference any related issues

## Organization Guidelines

```
docs/
├── processes/          # Core workflows and procedures
├── templates/          # Reusable project artifacts
├── best-practices/     # Proven approaches and team insights
└── guidelines/         # Standards and conventions
```

## Documentation Standards

- Use clear, concise language
- Include step-by-step instructions
- Add context about who should use this
- Link to related documents
- Keep documents up-to-date
- Use consistent formatting (Markdown)

## Review Process

1. Submit your contribution via Issue or Pull Request
2. Team leads and stakeholders review
3. Feedback and iterations
4. Approval and merge
5. Documentation goes live

## Issue Templates Available

### Process Documentation Template
Use this to document new or updated processes with:
- Process name and purpose
- Scope and audience
- Step-by-step instructions
- Responsible parties
- Dependencies
- Success criteria
- Review checklist

### Improvement Suggestion Template
Use this to propose improvements with:
- Current process reference
- Issue description
- Suggested improvement
- Impact assessment
- Additional context

## Questions?

Have questions about contributing? Open an issue or reach out to the team!
